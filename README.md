# Hafiza Javeria Saleem - Official Artist Showcase & Naat Portfolio

An executive, animated artist portfolio and Naat showcase website for the celebrated Naat Khawan **Hafiza Javeria Saleem (Jaweria Saleem)**.

## ✨ Features
- **Cool Islamic Aesthetics:** Deep midnight obsidian, vibrant cyan glow, oceanic sky blues, and champagne gold accents.
- **Ambient Canvas Particles:** Floating spiritual particle field and animated audio equalizer waveform.
- **Embedded YouTube Player:** Prominently highlights **Ramzan Special 2026** recitation (`38gk9rUNL4M`).
- **Interactive Theater Modal:** Stream popular hit recitations directly (*Madine Ka Safar Hai* - 27M+ views, *Pukaro Ya Rasool Allah* - 15M+ views, *Miran Waliyon Ke Imam* - 10M+ views, and more).
- **Categorized Recitations:** Instant filters for All, Most Popular, Ramzan & Hajj, Soulful Kalams, and Manqabat.
- **Artist Biography & Accolades:** Highlights her journey as a Hafiza-ul-Quran at age 10, international performance footprint across 20+ countries, and national recognition.
- **Executive Booking Form & Official Channels:** Direct management inquiries with 1-click email copying and verified social media links.

## 🚀 Getting Started

### Run Locally with Node.js
```bash
node server.js
```
Then visit [http://localhost:3000/](http://localhost:3000/) in your browser.

### Direct File Access
Simply open `index.html` in any web browser.
